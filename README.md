## 💡 The Problem
Financial planning is often perceived as complex, boring, and intimidating. Traditional calculators provide raw numbers but fail to educate the user on **why** those numbers matter, leading to unrealistic expectations and poor financial discipline.

## ✨ Our Solution
**FinCal** is a high-performance financial academy disguised as a premium goal-planner. We bridge the gap between "calculating" and "understanding" by combining **HDFC’s trusted financial logic** with **enterprise-grade gamification** and **interactive 3D visualizations**.

### Key Features
- **Educational Step-Wizard**: A 4-step journey that teaches concepts like Inflation and Risk through interactive visualizers before showing results.
- **Live Inflation Impact**: A real-time visualizer that shows users the "real" future cost of their goals.
- **Dynamic Risk Spectrum**: Animates returns and risks based on time-horizons, preventing irrational investment strategies.
- **Behavioral Scoring**: A "Financial Health Gauge" that rewards realistic assumptions and consistency.
- **Gamification Hub**: Earn XP, unlock badges (Curious Mind, Rational Investor), and compete on the global "Financial Integrity" Leaderboard.
- **SIP Time Machine**: A volatility simulator that visually demonstrates why staying invested through market ups and downs is the key to wealth.

## 🛠️ The Tech Stack
- **Frontend**: Next.js 15 (App Router), React, Tailwind CSS
- **3D Graphics**: Three.js & React Three Fiber (Financial Coin & Interactive Elements)
- **Animations**: Framer Motion (Micro-interactions & transitions)
- **State Management**: Zustand (Persistent Game State & Plans)
- **Form Handling**: React Hook Form + Zod
- **Icons**: Lucide React
- **Auth**: Clerk

## 🏃 How to Run Locally

1. **Clone the repo**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up Environment Variables**:
   Create a `.env.local` file with your Clerk API keys (see `.env.local.example`).
4. **Run the development server**:
   ```bash
   npm run dev
   ```
5. **Visit**: [http://localhost:3000](http://localhost:3000)

## 🏆 Hackathon Focus: Intelligence & Accountability
FinCal doesn't just calculate; it **accountability-checks** the user. If a user sets an unrealistic 25% return, the system penalizes their XP and Health Score, teaching them market realism. This ensures users don't just "plan"—they plan **rationally**.
